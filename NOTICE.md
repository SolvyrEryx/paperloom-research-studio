# Provenance and attribution

Paperloom is a standalone release of the newly written Rahul J research workspace, developed after evaluating [ViVaMaTe AI](https://github.com/preetmish086/ViVaMaTe-AI) as a reference for an academic research-preparation application.

This repository contains the newly written application, prompts, document/indexing core, PowerPoint/report exporters, tests, design, documentation and generated diagrams. It does not include ViVaMaTe's source modules, original app, assets, paper-context data, audio recordings or Git history. That upstream project did not provide a licence in the checkout reviewed, and its source has therefore not been relicensed or redistributed in this release.

The MIT licence applies to the Paperloom source and original visual assets included here. Installed third-party dependencies and the downloaded MiniLM model retain their respective licences. Windows/system fonts may be used to render the visual assets; font binaries are not distributed.

Branding: Paperloom · Research Studio by Rahul J. AI-assisted implementation and documentation were used during development. Academic submissions should follow the institution's attribution and AI-use requirements.
